Masuku Adventure Safaris

Public API

Machine-readable catalog of safari packages and Victoria Falls activities, plus booking inquiries. OpenAPI: /api/openapi.json.

Endpoints

  • GET /api/health — service status
  • GET /api/packages — safari packages
  • GET /api/packages/{slug} — one package
  • GET /api/activities — activities
  • GET /api/activities/{slug} — one activity
  • POST /api/inquiries — booking or contact inquiry
  • POST /api/mcp — Model Context Protocol (Streamable HTTP)

Discovery

  • API catalog (RFC 9727)
  • MCP server card
  • auth.md — agent registration
  • robots.txt · sitemap.xml

Example

curl https://masukusafaris.com/api/packages
curl -H "Accept: text/markdown" https://masukusafaris.com/
